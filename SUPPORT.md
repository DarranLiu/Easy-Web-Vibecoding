# Support

- Use [GitHub Discussions](https://github.com/DarranLiu/Easy-Web-Vibecoding/discussions) for setup questions, ideas, and workflow tips.
- Use a [bug report](https://github.com/DarranLiu/Easy-Web-Vibecoding/issues/new?template=bug_report.yml) for a reproducible defect.
- Use a [feature request](https://github.com/DarranLiu/Easy-Web-Vibecoding/issues/new?template=feature_request.yml) for a focused product proposal.
- Use private vulnerability reporting for security issues; see [SECURITY.md](SECURITY.md).

Sanitize screenshots, logs, commands, paths, IP addresses, hostnames, and environment output before posting. Never post a login token, API key, cookie, certificate, or private URL.

This is a volunteer-maintained project. Public questions and reports are handled when maintainer time is available; no response-time or compatibility SLA is provided.
