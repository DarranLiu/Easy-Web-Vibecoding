# Mist Coast

`mist-coast.png` is an independently AI-generated coastal background created for
this project. It contains no user screenshot, terminal contents, logo, identifying
landmark, or server information. No third-party photograph or screenshot was
copied into this asset; include this provenance note when packaging the project.

The glass preset loads it from this server only, once as a shared CSS background,
not once per terminal. No external image service is contacted by the app.
Mobile, data-saving, reduced-transparency, and forced-color modes use solid
surfaces instead. The image has no animation; CSS blurs only the background layer,
never the terminal text or ANSI cell backgrounds.
