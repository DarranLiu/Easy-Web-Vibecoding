# v0.2.0 - Hot updates and original-session recovery

## English

Update the shared CLI installation without restarting running windows, or explicitly restart a selected Codex, Claude Code or OpenCode back into its original conversation.

![Version management](../images/en/updates.png)

### What's new

- Compare the running window, shared installation and latest official version. Choose install only, update and restore, restart and restore, or roll back the installation when available.
- Record the exact original session, preserve supported launch settings, check compatibility before exit and verify recovery afterward. Missing or ambiguous identities are blocked rather than replaced with another conversation.
- Expand workspaces into session lists in the left sidebar. Split across projects without binding navigation to the screen layout; keep mobile and desktop layouts separate.
- Use a task/activity panel, conflict-aware file editor, read-only Git changes and bounded tmux history search.
- Switch recent sessions and insert native slash commands from a phone. Optional glass styling and restrained effects retain the original terminal input.

### Problems addressed

- Stale backend connections and separate old web executables after a manual resume.
- Restart reporting success when only `resume` appeared at the shell; delayed exit and missing-session safety.
- Codex history jumps, wheel/touch no-ops, short-pane and wrapper routing.
- An empty fourth cell in three-pane layouts and terminals failing to fit their container.
- Native input tint flicker and unnecessary full-screen redraws during Codex output.
- Accidental Ctrl+C interruptions: web copy shortcuts now copy only; use the separate confirmed interrupt action.
- Ambiguous historic update failures: installation and session recovery are tracked independently.

### Upgrade and limits

This is a backend and frontend upgrade. Back up private state outside the checkout, update dependencies, restart **only the web service**, then refresh the page. Existing native tmux tasks are not deliberately restarted. Review `KillMode=process` in your service configuration; the supplied example now includes it.

Install-only hot updates leave running processes on their existing version. Restart-and-restore can interrupt work and discard drafts. It recovers conversation identity/history, not an executing shell command or RAM after reboot. Rollback restores executable selection, not conversation schema. Unsupported installations or resume options are rejected, not assumed compatible.

The standalone release retains its signed-cookie and file protections. Documentation previews use synthetic fixtures; English labels are translated for documentation, not a claim that the app has a complete English locale.

See [update and recovery instructions](../UPDATES.en.md), [deployment](../DEPLOYMENT.en.md) and the [local verification record](v0.2.0-verification.md).

## 简体中文

这次主要把“更新程序”和“恢复原来的交互终端”做好：先装新版可以不停任务；需要切换当前窗口时，再明确重启并回到原来的对话。

![版本管理](../images/updates.png)

### 新增功能

- 一次看清当前窗口、共享安装、官方最新三个版本，支持仅更新、更新并恢复、重启并恢复，以及有备份时回退安装。
- 保存确切的原会话和受支持的启动设置，退出前检查兼容性，启动后验证原对话是否加载。不能确认时阻止恢复，不拿最近一条代替。
- 左侧工作区展开子窗口，跨项目分屏，切换工作区不改变已经打开的画面；手机和电脑各存自己的布局。
- 增加任务与活动面板、冲突检查的文件编辑、只读 Git 差异和有界 tmux 历史搜索。
- 手机最近会话、原生快捷命令；可选雾色玻璃、流光和拖尾，保留终端自己的输入栏。

### 解决过的问题

- 手动 resume 误连旧后台，或网页与 SSH 各用一套旧程序。
- 重启后只剩一条 `resume` 命令却被当成成功，以及退出较慢、原会话缺失时的保护问题。
- Codex 滚轮整页跳、滚不动、短窗口和包装进程识别不准，手机滑动受选择模式影响。
- 三窗重新分配后留下空白第四格，容器变宽或变窄却不重新适配。
- Codex 输出时原生输入底色闪烁，相同尺寸反复触发整屏刷新。
- 复制误退出程序：网页 Ctrl+C 现在只复制，中断改成单独按钮并确认。
- 旧的更新失败提示混淆“已安装”和“已恢复”，现在分别记录。

### 升级与边界

这次前后端都要更新。先在仓库外备份私有状态，再更新依赖、只重启 Web 服务，最后刷新页面，不要重启 tmux 或所有原生工具。已有 systemd 部署请核对 `KillMode=process`，新版示例已补上。

热更新不会让旧进程原地变新版；重启会打断所选工具，可能丢失草稿。恢复的是原会话和聊天历史，不是执行中的命令或重启前的内存。回退安装也不回滚会话格式。不支持的安装或参数会明确拒绝，不会假装兼容。

开源版原来的签名 Cookie、目录白名单、文件与预览保护仍然保留。文档预览全部使用合成数据；英文标签为文档翻译，不代表软件已具备完整英文语言包。
