# v0.2.0 verification / 验证记录

Local verification on 2026-10-16. These results describe this release candidate, not a completed GitHub Actions run or a guarantee that every native CLI version is compatible.

| Check | Result |
| --- | --- |
| Python suite with isolated tmux integration enabled | 190 tests: 187 passed, 3 optional native-CLI tests skipped |
| Playwright browser suite | 268 passed |
| Frontend JavaScript and backend observer syntax | Passed |
| Python syntax, shell syntax and Git whitespace checks | Passed |
| Distribution scan and local documentation links | No findings |

The Python suite covers original-session identity, restart and update failure paths, shared installation handling, terminal isolation, workspace persistence, signed-cookie authentication and file protection. Isolated tmux fixtures do not touch existing user sessions.

Browser tests cover workspace navigation, independent splits, three-pane placement, resize behavior, desktop and mobile scrolling, copy-only shortcuts, native input tint, themes, update controls and bilingual documentation previews. The APIs, WebSocket output and update metadata are mocked; these tests do not download a real CLI update, call a model or restart a user's terminal.

Documentation screenshots use synthetic sessions, paths and resource data. English labels are translated by the documentation fixture. Source scans check credential patterns, deployment identifiers, private addresses, runtime artifacts and missing links. These checks reduce accidental disclosure; they are not an independent security audit.

## 简体中文

以上是 2026-10-16 的本地验证结果，不代表 GitHub CI 已运行，也不能证明所有未来 CLI 版本都兼容。

- Python 共 190 项：187 项通过，3 项需要额外原生 CLI 环境的可选测试跳过。启用了独立 tmux 集成测试，不接触已有用户会话。
- 浏览器 268 项通过，覆盖分屏、缩放适配、滚动、手机交互、复制、主题、更新入口与双语文档预览。
- 浏览器使用模拟 API、终端输出和版本数据，不下载真实更新、不请求模型、不重启用户终端。
- 文档截图使用合成演示数据；英文标签由文档测试翻译。发布扫描未发现凭据、私人部署标识、运行状态文件或断开的本地文档链接。

测试与扫描不能保证没有任何缺陷。正式升级前仍应私密备份原生工具配置、会话记录及网页状态，并先在非关键会话上验证恢复。
